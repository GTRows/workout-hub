**Step A: Create `frontend/src/lib/time/iso-week.ts` (NEW file).**

Pure function module, ~25-35 lines. Reference convention: `frontend/src/lib/time/today.ts`.

Required export:
```ts
export function getCurrentIsoWeekRange(now: Date = new Date()): {
  start: Date;
  end: Date;
}
```

Behavior:
- ISO week starts Monday. Convert `now.getDay()` (Sun=0..Sat=6) to a Mon-start offset: `(getDay() + 6) % 7` gives 0 for Mon, 6 for Sun.
- `start = new Date(now)`, then `start.setDate(now.getDate() - offset)`, then `start.setHours(0, 0, 0, 0)`.
- `end = new Date(start)`, then `end.setDate(start.getDate() + 6)`, then `end.setHours(23, 59, 59, 999)`.
- Returns `{ start, end }` - both `Date` instances; the consumer compares `entry.startedAt` (parsed via `new Date(...)`) against this range.

Companion helper (same file):
```ts
export function isInRange(when: Date | string, range: { start: Date; end: Date }): boolean {
  const t = typeof when === "string" ? new Date(when).getTime() : when.getTime();
  return t >= range.start.getTime() && t <= range.end.getTime();
}
```

The file is pure, zero-import, deterministic. NO `any`. NO mutation outside the local `start`/`end` variables. The caller is responsible for parsing the backend's ISO 8601 strings.

**Step A: Create `frontend/src/lib/time/relative-date.ts` (NEW file).**

Pure function module, ~25-40 lines.

Required export (discriminated union return):
```ts
export type RelativeDate =
  | { kind: "today" }
  | { kind: "daysAgo"; days: number }
  | { kind: "absolute"; iso: string };

export function formatRelativeDays(
  then: Date | string,
  now: Date = new Date()
): RelativeDate
```

Behavior:
- Parse `then` to a `Date` if string.
- Compute the calendar-day difference: zero out both dates' time-of-day (`setHours(0, 0, 0, 0)`) and divide the millisecond delta by 86_400_000.
- If `days <= 0` -> return `{ kind: "today" }` (future or today is treated as today; the dashboard never shows future weight entries).
- If `1 <= days <= 7` -> return `{ kind: "daysAgo", days }`.
- If `days > 7` -> return `{ kind: "absolute", iso: <YYYY-MM-DD> }` where the iso is built from `then`'s zeroed-out date.

The function is pure, zero-import, deterministic. NO i18n inside the helper - the consumer translates via `next-intl`.
