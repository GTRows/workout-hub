**Step A: Create `frontend/src/lib/auth/use-session-expired-redirect.ts` (NEW file).**

Single hook export, ~30-45 lines. Lives next to `token-store.ts` and `login-schema.ts` per the feature-sliced layout in `lib/auth/`.

Hook contract:
```ts
export function useSessionExpiredRedirect(): void
```

Behavior:
- On mount: subscribes to `subscribeAccessToken` (from `token-store.ts:36`).
- The subscriber receives the new token value. If the new value is `null` AND the previous value was non-null AND `getRefreshToken()` is also `null` (the refresh interceptor cleared both — see `client.ts:60-71`), the hook redirects.
- Redirect target: `"/login?reason=session-expired&next=" + encodeURIComponent(currentPathname)`.
- No-op cases:
  - `pathname.startsWith("/login")` (user is already on the login page; e.g. manual logout that already redirected).
  - The transition is `null -> null` (no real change).
  - The hook is server-side rendering (no `window`); `useEffect` short-circuits when SSR.
- Cleanup: returns the unsubscribe from `subscribeAccessToken` so React unmounts cleanly.

Implementation sketch:
```ts
"use client";

import { useEffect } from "react";
import { usePathname, useRouter } from "next/navigation";
import { getRefreshToken, subscribeAccessToken } from "@/lib/auth/token-store";

export function useSessionExpiredRedirect(): void {
  const router = useRouter();
  const pathname = usePathname();
  useEffect(() => {
    let lastSeen: string | null = null;
    const unsubscribe = subscribeAccessToken((next) => {
      const previous = lastSeen;
      lastSeen = next;
      if (next !== null) return;
      if (previous === null) return;
      if (getRefreshToken() !== null) return;
      if (pathname.startsWith("/login")) return;
      router.replace(
        "/login?reason=session-expired&next=" + encodeURIComponent(pathname)
      );
    });
    return unsubscribe;
  }, [router, pathname]);
}
```
