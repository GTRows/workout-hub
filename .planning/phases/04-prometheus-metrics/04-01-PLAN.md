```java
@RestController
public class MetricsController {

    private final PrometheusScrapeEndpoint scrape;

    public MetricsController(PrometheusScrapeEndpoint scrape) {
        this.scrape = scrape;
    }

    @GetMapping(value = "/metrics", produces = "text/plain; version=0.0.4; charset=utf-8")
    public ResponseEntity<String> metrics() {
        WebEndpointResponse<String> response = scrape.scrape(TextOutputFormat.CONTENT_TYPE_004, null);
        return ResponseEntity.status(response.getStatus())
                .contentType(MediaType.parseMediaType("text/plain; version=0.0.4; charset=utf-8"))
                .body(response.getBody());
    }
}
```

Create `frontend/src/app/api/metrics/route.ts`:

```ts
export const dynamic = "force-dynamic";
export const runtime = "nodejs";

const startTime = Date.now();

export function GET() {
  const memUsage = process.memoryUsage();
  const uptimeSec = process.uptime();
  const lines = [
    "# HELP nodejs_process_uptime_seconds Process uptime in seconds.",
    "# TYPE nodejs_process_uptime_seconds gauge",
    `nodejs_process_uptime_seconds ${uptimeSec.toFixed(3)}`,
    "# HELP nodejs_process_resident_memory_bytes Resident set size in bytes.",
    "# TYPE nodejs_process_resident_memory_bytes gauge",
    `nodejs_process_resident_memory_bytes ${memUsage.rss}`,
    "# HELP nodejs_process_heap_used_bytes V8 heap used in bytes.",
    "# TYPE nodejs_process_heap_used_bytes gauge",
    `nodejs_process_heap_used_bytes ${memUsage.heapUsed}`,
    "# HELP nodejs_process_heap_total_bytes V8 heap allocated in bytes.",
    "# TYPE nodejs_process_heap_total_bytes gauge",
    `nodejs_process_heap_total_bytes ${memUsage.heapTotal}`,
    "# HELP nodejs_process_external_memory_bytes External memory in bytes.",
    "# TYPE nodejs_process_external_memory_bytes gauge",
    `nodejs_process_external_memory_bytes ${memUsage.external}`,
    "# HELP workouthub_frontend_start_time_seconds Unix timestamp when the process started.",
    "# TYPE workouthub_frontend_start_time_seconds gauge",
    `workouthub_frontend_start_time_seconds ${(startTime / 1000).toFixed(3)}`,
  ];
  return new Response(lines.join("\n") + "\n", {
    status: 200,
    headers: { "content-type": "text/plain; version=0.0.4; charset=utf-8" },
  });
}
```

`startTime` captured at module load (single instance per Node process under Next standalone). All other metrics read live from `process.*`.

Do NOT add `prom-client` or any other npm dependency. Do NOT instrument React Server Components or per-request metrics in this task - that is feature work for a future phase. The contract requires "HTTP request count and duration histogram" (section 9.1) but per-request counters need a custom Next middleware integration that is NOT trivial in App Router and would expand scope. Track that follow-up as ISSUES entry rather than blocking this plan.

describe("/api/metrics", () => {

    const res = GET();
    expect(res.status).toBe(200);
    expect(res.headers.get("content-type")).toContain("text/plain");

});
